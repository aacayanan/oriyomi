Paper-Fold as shipped

Measured from globals.css, hero.html, and component color literals. The world works; a handful of values undercut it.

Working

  • Body text 15.7:1. Sumi on washi clears AA with room to spare.
  • Roles are stable: vermilion = action and crease, gold = active state, sumi = text, hairlines = structure.
  • Luminance ladder reads correctly: text → meta → line, top to bottom.
  • Focus ring in vermilion passes 4.24:1 on washi; button hover deepens to 6.37:1.
  • The warm-paper world is coherent. Every hue belongs to it.

Not working

  • Gold state mark #C9A227 → 2.10:1 on washi. Fails even the 3:1 UI floor, yet gold carries the active fold, the progress dot, and the sentence margin dot.
  • Timestamp strip #AB9D99 → 2.28:1. Data text fails AA outright.
  • Meta ink drifts: the token #6e645c passes at 5.01:1, but shipped UI uses #80756E (3.89:1) in Quiz and TextReader. 17 call sites sit below body AA.
  • Outline-button borders #C9BEB0 → 1.59:1. Interactive control boundaries are near-invisible.
  • Button’s gold dot 2.92:1 on vermilion: just under the UI floor.
  • Vermilion drifted from the approved comp’s #D83A2E to #C34838. Chroma loss: it reads terracotta, not ink.
  • Zero cool counterweight: active sentence #1D1210 vs body #1A1513 differ by weight alone.
  • No dark mode exists, and colors are hardcoded hex per component. Dark needs semantic roles first.
